개인정보처리방침

유튜브 채널 관리 도구 · 시행일 2026-10-02 · 홈

1. 접근하는 정보

사용자가 Google 계정으로 동의한 범위 안에서 다음 정보에 접근합니다.

  • 본인 유튜브 채널의 기본 정보(채널 이름·ID·구독자 수)
  • 본인 채널 영상의 목록·제목·설명·공개 상태·예약 시각·조회수 등 통계
  • 본인 영상의 YouTube 분석 지표(구독 전환 등)

2. 이용 목적

본인 채널에 영상을 올리고 공개 예약을 걸며, 채널·영상 성적을 확인하는 데에만 씁니다. 그 밖의 목적으로는 쓰지 않습니다.

3. 저장 위치와 보관

이 도구는 사용자 PC 에서만 실행됩니다. 받은 정보와 로그인 토큰은 사용자 PC 의 파일에만 저장되며, 개발자가 운영하는 서버로 보내지 않습니다. 사용자가 그 파일을 지우면 모두 사라집니다.

4. 제3자 제공

받은 정보를 제3자에게 판매·공유·전송하지 않습니다(요청을 처리하기 위한 Google API 호출은 예외).

5. Google API 사용자 데이터 정책

이 도구가 Google API 에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요구사항 포함)을 따릅니다.

6. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 사용자는 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.

7. 권한 철회

언제든 Google 계정 → 서드파티 액세스에서 이 도구의 권한을 지울 수 있습니다. 지우면 이 도구는 더 이상 계정 정보에 접근하지 못합니다.

8. 문의

Google 동의 화면에 표시된 개발자 지원 이메일로 문의해 주세요.

Privacy Policy (English)

Data accessed. With the user's consent: basic info of the user's own YouTube channel (name, ID, subscriber count); the user's own videos (list, title, description, privacy status, scheduled publish time, view statistics); and YouTube Analytics metrics for those videos.

Use. Only to upload videos to the user's own channel, schedule their publishing, and show channel/video performance to the user.

Storage. The tool runs only on the user's computer. Data and OAuth tokens are stored only in local files there and are never sent to any developer-operated server.

Sharing. Data is not sold, shared, or transferred to third parties (other than calling Google APIs to fulfil the user's requests).

Limited Use. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services. This tool uses YouTube API Services; users are bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access. At any time via Google Account → Third-party access.

Contact. The developer support email shown on the Google consent screen.
